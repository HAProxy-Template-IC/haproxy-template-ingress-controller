# Operate HAPTIC

Use these guides after [installing HAPTIC](../getting-started.md). Start with
[fleet diagnostics](diagnostics.md) when configuration isn't reaching HAProxy,
or [routing troubleshooting](../troubleshooting.md#routing-issues) when a
request doesn't reach its application.

## See what's happening

| Task | Guide |
| --- | --- |
| Check controllers, validation, and every HAProxy pod | [Fleet diagnostics](diagnostics.md) |
| Find the route, backend, and policy outcome for a request | [Access logging](access-logging.md) |
| Set up metrics, alerts, and dashboards | [Monitoring](monitoring.md) |
| Inspect rendered files, events, and deployment decisions | [Debugging](debugging.md) |
| Investigate a failed install, unavailable pod, or routing error | [Troubleshooting](../troubleshooting.md) |

## Run and update the installation

| Task | Guide |
| --- | --- |
